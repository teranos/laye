Main branch is the code invariant. Everything on it is verified. Testing happens on the branch — we push, we deploy the branch's artifacts to the one live URL we have, and we walk through it end-to-end there. We do not have two environments and we don't need them. Verification always precedes merge. The moment we merge is the moment we squash into one exemplary commit — never before. Putting unverified code on main as a shortcut, to make CI fire or to make deploys easier or for any other reason, is forbidden.
